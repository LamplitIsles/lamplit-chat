# Pi 0.87.1 storage fixture

`pi-0871-writes.json` contains synthetic, test-owned committed writes generated by
`@earendil-works/pi-agent-core` 0.87.1, not an export of a user's session. It covers
linked messages, two branch tips, lane configuration, session name, a list and
usage linked to an assistant entry. The fixed timestamp and IDs are intentional.

To reproduce, install exact `@earendil-works/pi-agent-core@0.87.1` and
`@earendil-works/pi-ai@0.87.1` with npm in an isolated directory, then run
`generate-pi-0871.mjs` with that installation's core package directory as its sole
argument. Compare stdout with the committed JSON. The generator checks the core
version and uses its `prepareStorageCommit` and `validateCommittedWrites` APIs.
The runtime test consumes only the committed JSON; no old package, temporary
installation, credentials or user data is required to run it.
